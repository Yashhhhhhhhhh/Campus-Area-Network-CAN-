# **Campus Area Network (CAN) Simulation**

This repository contains the mini-project for designing and simulating a **Campus Area Network (CAN)** for **Vidyalankar Institute of Technology (VIT), Mumbai**, using Cisco Packet Tracer.


## **Project Overview**

The project involves creating a scalable and secure network infrastructure connecting various departments, labs, and administrative offices within the VIT campus. The network supports essential services such as:
- **VLANs** for departmental isolation.
- **DNS** for domain name resolution (`www.vit.edu.in`).
- **FTP Server** for file sharing (`ftp.vit.edu.in`).
- **Web Hosting** for hosting the campus website.

---

## **Features**
1. Logical network segmentation using VLANs.
2. Dynamic routing with RIP protocol.
3. DNS setup for domain name resolution.
4. FTP server configuration for file sharing.
5. Web hosting service deployment.

---

## **Technologies Used**
- **Simulation Tool**: Cisco Packet Tracer  
- **Hardware Components**: Cisco Routers, Switches, Servers, PCs  
- **Protocols**: RIP, HTTP/HTTPS, FTP, DNS
